=== Mayfly ===
Block theme for Mayfly Digital. No plugin, no page builder.

Structure
- theme.json: colours, type, spacing. Change a colour here and it changes everywhere.
- templates/: page.html, index.html, 404.html. The home page is a normal page set as the front page.
- parts/: header.html, footer.html.
- patterns/: one pattern per page (home, services, process, about, contact) plus header and footer.
  Each page's content is that pattern, so it is editable in the standard editor.
- assets/css/axis.css: the axis layout (the only custom CSS).
- functions.php: fonts in the editor, the axis stylesheet, the JSON-LD schema.

Fonts: Jost and Newsreader, SIL Open Font License, bundled in assets/fonts.
Images: the Mayfly Digital wordmark and the "AI Does the Work" cover belong to their owners.
